Mockup 3 — Snapping, Play/Loop, Tooltips, Zoom

Same surface, paths, gradients, and readout as Mockup 2. New: the slider snaps to tangency points (green ticks), a play button auto-sweeps for lecture use, hover tooltips narrate the controls, and the 3D panel now supports scroll/button zoom. The true-3D vector/marker style has been removed — flat is the only style now, with a billboarded marker so it still reads as a true circle from any angle.
